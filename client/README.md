# Enterprise IT Support & Issue Tracking Application

## Project Overview

Enterprise IT Support & Issue Tracking Application is a full-stack web application developed as part of my Cloud & DevOps Internship.

The application helps employees create, manage, assign and track IT support tickets through a secure authentication system.

---

## Tech Stack

### Frontend
- React.js
- Axios
- React Router
- React Icons
- Chart.js

### Backend
- Node.js
- Express.js
- JWT Authentication
- Bcrypt
- Multer
- Nodemailer

### Database
- MySQL

### Deployment (In Progress)
- AWS EC2
- GitHub
